# Resampling-Methods-in-Machine-Learning
This repository contains various implementations of machine learning techniques, including regression analysis, cross-validation, and bootstrap resampling, using Python and relevant statistical libraries.

Overview

This repository demonstrates key machine learning concepts and statistical methods, with a focus on regression modeling and model evaluation techniques. It includes:

Linear and polynomial regression

Cross-validation methods

Bootstrap resampling for standard error estimation

Dataset

The dataset used includes automobile specifications and financial portfolio data. The key datasets include:

Auto dataset: Contains variables related to car features and fuel efficiency.

Portfolio dataset: Includes asset return data for portfolio allocation analysis.

Implemented Methods

Regression Analysis

Simple Linear Regression: Predicting mpg based on horsepower.

Polynomial Regression: Exploring higher-degree polynomial terms to improve model accuracy.

Ordinary Least Squares (OLS): Model fitting using the statsmodels library.

Model Evaluation

Cross-Validation: Using KFold and Leave-One-Out Cross-Validation (LOOCV) to assess model performance.

Mean Squared Error (MSE): Evaluating prediction errors of different models.

Bootstrap Resampling

Portfolio Allocation Analysis: Estimating the standard error of portfolio allocation decisions using bootstrapping.

Bootstrap Standard Error Calculation: Implementing a custom function to estimate the variability of statistical metrics.
